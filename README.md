# 🌿 Verde & Saúde Natural

O **Verde & Saúde Natural** é um projeto de desenvolvimento web criado para oferecer uma plataforma de produtos naturais. A aplicação permite visualizar o catálogo de produtos, adicionar produtos ao carrinho, realizar pagamentos e acompanhar pedidos.

O projeto foi desenvolvido com uma divisão entre **Front-End (UI)** e **Back-End (API)**, utilizando tecnologias web e Java com Spring Boot.

---

## 🎨 Projeto UI — Front-End

A interface do projeto possui as seguintes telas:

1. Splash / Home
2. Login
3. Cadastro de clientes
4. Cadastro de produtores
5. Catálogo de produtos
6. Carrinho de compras
7. Pagamento
8. Acompanhamento de pedidos
9. Entregador / Minhas Entregas

### Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

### 8 tarefas do projeto UI

| Código | Tarefa | Verificação |
|---|---|---|
| UI-01 | Catálogo de produtos | Navegação e exibição dos produtos |
| UI-02 | Carrinho de compras | Adição e cálculo dos valores |
| UI-03 | Cadastro de clientes | Formulário e integração com API |
| UI-04 | Cadastro de produtores | Formulário disponível |
| UI-05 | Visualização dos produtos | Fotos, nomes e preços |
| UI-06 | Acompanhamento de pedidos | Tela visual verificada |
| UI-07 | Processamento e tela de pagamento | Registro de pagamento na API |
| UI-08 | Efetuar pedido | Finalização integrada à API |

## ⚙️ Projeto API — Back-End

### Tecnologias

- Java 21
- Spring Boot 4.0.8
- Spring Web
- Spring Data JPA
- H2 Database
- Maven
- Git
- GitHub

### 8 tarefas do projeto API

| Código | Tarefa | Verificação |
|---|---|---|
| API-01 | Estrutura inicial da API | Inicialização do Spring Boot |
| API-02 | Configuração do banco de dados | Conexão com H2 |
| API-03 | Cadastro de clientes | Postman — POST e GET |
| API-04 | Cadastro de produtores | Postman — POST e GET |
| API-05 | Produtos orgânicos | Postman |
| API-06 | Catálogo de produtos | Postman — consulta |
| API-07 | Registro de pedidos | Postman — POST |
| API-08 | Consulta e atualização de pedidos | Postman — GET e PUT |
